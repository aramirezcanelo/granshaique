Aviso de privacidad y cookies

Versión 2

Este aviso explica qué información utiliza la plataforma, para qué la necesita y cómo funciona la cookie esencial de sesión.

Transparencia sobre el responsable

Este proyecto todavía no publica una identidad legal ni un domicilio del responsable. La comunidad que administra Gran Chaique debe definir y comunicar esos datos antes de considerar este borrador un aviso integral definitivo. No se incluyen datos personales de contacto aquí.

1. Datos que se utilizan

  • Cuenta: nombre de usuario, identificador comunitario y rol de acceso.
  • Autenticación: contraseña, guardada como hash criptográfico y no como texto legible; token aleatorio de sesión; versión del aviso y fecha de aceptación.
  • Actividad educativa: progreso, calificaciones, respuestas y estado de ejercicios.
  • Contenido de la plataforma: materiales y archivos que la administración incorpora para la comunidad.
  • Seguridad: datos técnicos transitorios necesarios para validar el inicio de sesión y limitar intentos automatizados, incluida la dirección IP durante controles temporales en memoria.

La plataforma no solicita deliberadamente datos personales sensibles. Evita incluir información sensible o de terceras personas en respuestas, nombres de usuario y materiales.

2. Finalidades

La información se usa para crear y administrar cuentas, autenticar el acceso, mostrar cursos y materiales, registrar el progreso y las respuestas, calcular calificaciones, prestar soporte y proteger el servicio frente a accesos no autorizados o abuso.

La versión y fecha de aceptación del aviso se asocian a la cuenta para dejar constancia de la aceptación. El navegador también recuerda localmente si aceptaste o rechazaste las cookies para conservar tu elección y permitirte cambiarla. No se usan cookies publicitarias ni se integra una herramienta de analítica en el código del proyecto.

3. Cookie necesaria de sesión

La notificación de acceso permite aceptar o rechazar las cookies esenciales. Al aceptar, se habilita una cookie temporal de seguridad; solo cuando el inicio de sesión termina correctamente, el servidor crea la cookie session. Esta mantiene el acceso autenticado entre solicitudes; sin ella no es posible usar una cuenta. No se utiliza para publicidad ni seguimiento entre sitios.

Duración máxima
7 días; la sesión del servidor puede terminar antes por seguridad o por reinicio del servicio.
Protección
HttpOnly, SameSite=Strict y, en producción con HTTPS, Secure. JavaScript no puede leer su token.
Verificación de acceso
La cookie temporal login_challenge protege el inicio de sesión contra automatización; vence en pocos minutos, se elimina al validar el intento o rechazar las cookies.
Preferencia en el dispositivo
El navegador recuerda localmente si aceptaste o rechazaste las cookies y ofrece una opción para cambiar tu decisión. Esta preferencia no contiene el token de sesión.

Si rechazas, no se habilita el acceso y no se prepara la cookie temporal ni se crea la cookie de sesión. Puedes cambiar tu decisión con Cambiar preferencia en la pantalla de acceso, o borrar los datos del sitio desde las opciones del navegador.

4. Dónde se guarda y con quién se comparte

Las cuentas, el contenido y el progreso se guardan en la base de datos y el almacenamiento configurados para el servicio. El proveedor de alojamiento procesa solicitudes y datos técnicos para entregar la aplicación. Los datos no se venden ni se comparten para publicidad.

Al abrir videos insertados desde YouTube, el navegador se conecta con ese proveedor y se aplican sus propias condiciones y prácticas de privacidad. También puede entregarse información cuando una autoridad competente lo exija conforme a la ley.

5. Conservación y seguridad

La cuenta, el progreso y las respuestas se conservan mientras la cuenta exista y sean necesarios para operar el servicio; la administración puede eliminar una cuenta. Los intentos de acceso y retos de seguridad son temporales y se guardan en memoria del proceso. Se aplican controles como contraseñas con hash, sesiones protegidas, límites de intentos y conexiones cifradas en producción.

6. Tus derechos y solicitudes

Puedes solicitar acceso, rectificación, cancelación u oposición (derechos ARCO) y hacer preguntas sobre el tratamiento de tus datos mediante el canal de soporte de la comunidad. Si no puedes iniciar sesión, utiliza el canal por el que recibiste acceso para contactar a la administración. La identidad y el domicilio del responsable deben ser comunicados por la comunidad administradora.

7. Cambios a este aviso

Los cambios se publicarán en esta página con una nueva versión. Si un cambio requiere renovar la decisión, la plataforma volverá a mostrar la notificación antes del acceso.
