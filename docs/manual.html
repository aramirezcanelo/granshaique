Crear, ordenar y eliminar contenido

  1. En Gestión de cursos, elige un tipo de ejercicio o material.
  2. Completa el título, las instrucciones y las opciones necesarias.
  3. Para adjuntar un archivo, selecciónalo y espera a que termine la carga.
  4. Pulsa Publicar o Guardar. Los ejercicios se muestran en el orden configurado.
  5. En Ordenar ejercicios, usa las flechas o arrastra el control para cambiar posiciones.
  6. Marca las casillas junto a varios ejercicios y pulsa Eliminar seleccionados. Los separadores se eliminan uno por uno.

Abrir o cerrar inscripciones

Abre el Dashboard y selecciona Gestión de usuarios. En la parte superior de esa vista aparece la tarjeta destacada Inscripciones públicas, con el estado actual y el botón correspondiente. Pulsa Abrir inscripciones para permitir nuevas cuentas desde la pantalla de acceso; pulsa Cerrar inscripciones para detenerlas. El cambio se guarda en el servidor y se refleja automáticamente en las pantallas de acceso abiertas. La administración puede seguir creando usuarios desde esta vista aunque las inscripciones públicas estén cerradas.

Antes de eliminar

La eliminación de ejercicios o usuarios no se puede deshacer desde la interfaz. Confirma el elemento correcto y conserva respaldos operativos de la base de datos y los archivos.

5. Administra cuentas y roles

En el panel alterna a Gestión de usuarios y busca por ID diario o nombre de usuario. Los IDs usan seis cifras de fecha y dos o más cifras de secuencia, con formato AAMMDDNN.

A

Crear una cuenta

Pulsa + Usuario, escribe usuario y contraseña, elige el rol y selecciona Crear.

B

Cambiar contraseña

Escribe una nueva en el campo de la cuenta y guarda. Si se deja vacío, se conserva la contraseña actual.

C

Asignar admin

Cambia el rol a admin solo a personas que deban crear contenido o gestionar cuentas.

Privacidad

Las contraseñas se almacenan protegidas y no se pueden consultar. Para recuperar acceso, establece una clave nueva y compártela por un canal privado.

6. Ayuda rápida

No puedo iniciar sesión

Comprueba usuario y contraseña. Si persiste, solicita al administrador que revise la cuenta o establezca una contraseña nueva.

No aparecen ejercicios

Actualiza el curso. Si continúa vacío, confirma con el administrador que haya publicado contenido.

No se guarda una respuesta o archivo

Revisa tu conexión, espera el mensaje de confirmación y vuelve a intentarlo. Para archivos, comprueba que la carga finalice.

La página muestra una vista de acceso local

El archivo abierto con doble clic es una previsualización. Para usar cuentas, guardar progreso y administrar cursos, abre la dirección del servidor de tu institución.

El video o documento no abre

Algunas vistas requieren internet o permiten abrir el archivo descargado. Contacta al administrador si el enlace está roto.

7. Accesibilidad y comodidad

Usa el teclado

Pulsa Tab para avanzar y Mayús + Tab para retroceder. El contorno visible señala el control activo; pulsa Enter o Espacio para seleccionarlo. En la sopa de letras, usa las flechas para recorrer el tablero. En Pares, selecciona primero un concepto y después su definición; en Memorama, activa las cartas con Enter o Espacio y recórrelas con las flechas.

Ajusta la vista

La interfaz se adapta a pantallas pequeñas. Puedes ampliar el contenido con los controles de zoom del navegador. Las animaciones respetan la preferencia de movimiento reducido del dispositivo.

Los botones y opciones tienen áreas táctiles amplias, y los campos muestran su foco al navegar con teclado.
